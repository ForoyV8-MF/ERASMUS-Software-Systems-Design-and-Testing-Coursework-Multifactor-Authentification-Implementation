# Software Design and Testing - CourseWork

## Presentation

This is an imitation of a Multi Factored Authentification Interface made from Java Swing.

## Running

For running this project, go to the MFA directory, and there you can either :

- Run the Terminal version by typing "make run_Terminal_MFA"
- Run the GUI version (which is the best one because this is the whole point of this project) by typing "make run_GUI_MFA"
